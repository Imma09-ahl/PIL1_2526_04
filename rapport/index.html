2. Mode de fonctionnement interne

Notre équipe est composée de 7 membres, chacun ayant travaillé sur une fonctionnalité précise du projet sur sa propre branche Git afin d'éviter les interférences.

Nous avons organisé des réunions régulières et des séances de travail via Google Meet pour suivre l'avancement, résoudre les difficultés et maintenir la cohérence globale du développement.

Nous avons rencontré des difficultés liées à la gestion des branches Git, mais grâce à la collaboration et à la communication, nous avons pu les résoudre et poursuivre le développement.

Outils utilisés

  • Git / GitHub — versionnement et collaboration
  • Google Meet — réunions d'équipe
  • Python / Flask — backend
  • MySQL — base de données
  • HTML, CSS, JavaScript, Tailwind CSS — frontend

4. Conception du projet

Architecture client-serveur

L'application suit une architecture modulaire en couches :

  • Présentation : templates Jinja2 + CSS/JS
  • Routes : Blueprints Flask (auth, profil, compétences, matching, messages)
  • Services : logique métier (auth_service, matching_service)
  • Modèles : accès SQL (user, competences, message, matching)
  • Données : MySQL

Structure du dépôt

app/
  routes/       → endpoints HTTP
  models/       → requêtes SQL
  services/     → logique métier
  templates/    → pages HTML
  static/       → CSS, JS, images
database/
  schema.sql    → structure BDD
rapport/
  index.html    → ce document

5. Base de données

SGBD : MySQL. Fichier : database/schema.sql

TableDescription
utilisateurComptes, profils (nom, email, filière, bio, format mentorat…)
competenceMatières fortes (fort) et lacunes (faible)
disponibiliteCréneaux horaires par jour
matchingRésultats mentor/mentoré avec score
conversationPaires d'utilisateurs en discussion
messageMessages textuels avec horodatage

Algorithme de matching

  • 50 % — compatibilité compétences (forts mentor ∩ lacunes mentoré)
  • 30 % — créneaux horaires communs
  • 20 % — proximité filière et niveau

6. Instructions de déploiement

# 1. Cloner le dépôt
git clone https://github.com/Imma09-ahl/PIL1_2526_04.git
cd PIL1_2526_04

# 2. Environnement Python
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt

# 3. Base de données
mysql -u root -p < database/schema.sql

# 4. Variables d'environnement (optionnel)
set SECRET_KEY=votre_cle_secrete
set MYSQL_PASSWORD=votre_mdp

# 5. Lancer
python run.py

Accès : http://localhost:5000

7. Manuel d'utilisation

Inscription et connexion

  1. Accéder à la page d'accueil et cliquer sur S'inscrire
  2. Renseigner nom, prénom, e-mail, téléphone et mot de passe
  3. Se connecter → redirection vers le tableau de bord

Compléter son profil

  1. Menu Profil → Modifier
  2. Renseigner filière, niveau, bio, photo
  3. Ajouter matières maîtrisées et matières où vous avez besoin d'aide
  4. Définir vos disponibilités horaires

Compétences et disponibilités

Page Compétences : ajouter/supprimer matières, créneaux et format de séance (présentiel, en ligne, les deux).

Matching

Page Matching : consulter les mentors recommandés avec score, matières communes et créneaux compatibles. Cliquer sur Contacter pour ouvrir une conversation.

Messagerie

Page Messages : liste des conversations, envoi de messages textuels, réception en temps réel (rafraîchissement automatique).
